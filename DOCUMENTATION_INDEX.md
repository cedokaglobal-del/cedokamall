## ❓ FREQUENTLY ASKED QUESTIONS

**Q: Can I change the product categories?**
A: Yes, edit `src/data/products.ts` and update the categories array.

**Q: How do I enable/disable flash deals?**
A: Comment/uncomment the flash deals section in `src/pages/Index.tsx`

**Q: Can I change security settings?**
A: Yes, all security config is in `src/config/security.ts`

**Q: How do I add authentication?**
A: See `BACKEND_SECURITY_GUIDE.ts` for JWT implementation recommendations.

**Q: Is this production-ready?**
A: Yes, but requires backend API implementation and HTTPS setup.

**Q: Can I customize the admin dashboard?**
A: Yes, modify files in `src/pages/Admin*.tsx` and `src/components/Admin*.tsx`
